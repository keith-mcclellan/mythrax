**Severity:** Medium

**File:** `mythrax-core/src/cognitive/paging.rs`
**Line:** 72

**Description:**
Critical agent virtual paging functions `extract_symbols` and `page_code_block` in `mythrax-core/src/cognitive/paging.rs` lack test coverage. These functions are responsible for parsing source code and extracting symbols. If the parsing logic (e.g., regex for generic type parameters like `fn name<T>(...)`) is flawed or misses complex function signatures, it introduces risks of silent extraction and code substitution failures during agent code modification tasks.

**Minimal Reproducible Scenario:**
If an agent tries to modify a Rust function with generic bounds like `pub fn parse_data<T: Clone + Debug>(input: &str) -> T { ... }`, `extract_symbols` might silently fail to capture it, causing the agent to hallucinate or fail the patch because the symbol is missing from its paged view.

**Suggested Fix:**
Add comprehensive unit tests in `mythrax-core/src/cognitive/paging.rs` (or a dedicated test module) covering `extract_symbols` and `page_code_block`. Ensure the extraction logic robustly handles complex signatures (generics, lifetimes, async fns) or uses a real AST parser rather than brittle string/regex heuristics.
